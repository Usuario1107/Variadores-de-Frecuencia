# Guía de Operación de la Consola (HMI) - Yaskawa JVOP-130

## 1. Indicadores LED Superiores
*   **DRIVE:** Iluminado cuando el variador está en modo de operación (Drive mode). Apagado cuando está en modo programación.
*   **FWD / REV:** Indican la dirección actual (adelante o reversa).
*   **REMOTE (SEQ y REF):** Indican el origen del comando. Si el LED está apagado, el control es Local (por teclado). Si el LED está encendido, el control es Remoto (por terminales externos/PLC).

## 2. Teclado de Control y Navegación
*   **LOCAL / REMOTE:** Conmuta entre control por teclado y control por terminales externos.
*   **RUN / STOP:** Arranca y detiene el motor (válido solo en modo Local).
*   **JOG:** Ejecuta el motor a una frecuencia baja de prueba (6 Hz por defecto).
*   **MENU:** Accede al árbol de menús (Initialize, Programming, etc.).
*   **DATA / ENTER:** Selecciona un ítem o guarda un valor modificado.
*   **ESC:** Regresa al nivel anterior del menú sin guardar cambios.
*   **Flechas (▲/▼):** Desplazamiento por menús y cambio de valores numéricos.
*   **RESET (◄):** Borra fallas activas y mueve el cursor al editar.

## 3. Árbol de Menús Principales
El equipo agrupa los parámetros en:
*   **U (Monitor):** Para ver datos en vivo (Frecuencia U1-01, Corriente U1-03, Voltaje DC U1-07).
*   **U2 (Fault Trace):** Datos de la falla actual.
*   **U3 (Fault History):** Registro de las últimas 4 fallas (Código y variables de operación).
*   **A (Initialize):** Idioma, selección de método de control.
*   **b/C/d/E/H/L (Programming):** Configuración de parámetros de motor, rampas, protección, etc.

## 4. Procedimiento para Diagnóstico de Fallas
Si el equipo falló, presione **MENU** > busque **U3 (Fault History)** > presione **DATA/ENTER**. Use las flechas para leer los códigos de falla (`OH`, `OC`, `OL1`, etc.) y las condiciones (corriente, frecuencia) en las que se detuvo el equipo.
